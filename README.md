# OLLIE（仮）

ドット絵のスケーターゲーム。**画面をタップするとオーリー、上へなぞるとキックフリップ、
下へなぞるとポップショウビット。**

種（シード）から地面が作られるので、**同じ景色は二度と出てきません。**

素のWeb技術（HTML/CSS/JavaScript・ビルド不要）で作成。オフライン（PWA）対応。

---

## ★これは公開用のコピーです

**開発は `dot-ollie/` のほうで行います。** ここには「遊ぶのに要るファイル」だけが入っています。

★**このフォルダを直接いじらないでください。** 直しても、次の反映で上書きされます。

---

## ★★島さんへ —— 公開のしかた（初回だけ）

1. **GitHub Desktop** でこのフォルダを開く
   （File → Add local repository → `ClaudeProjects/dot-ollie-web` を選ぶ）
2. **「Publish repository」を押す**
   ★**「Keep this code private」のチェックを外す**（外さないとページが公開されません）
3. GitHub のページで **Settings → Pages** を開き、
   **Branch: `main` / `root`** にして **Save**
4. 数分待つと `https://shima-nft.github.io/dot-ollie-web/` で開けます
5. iPhone の Safari で開き、共有ボタン →「**ホーム画面に追加**」
   → ★**電波が無くても遊べます**（オフライン対応）

## 2回目からは

**「Push origin」ボタンを押すだけ**です（`dot-calc-web` と同じ運用）。

## ★うまく開かないとき

| こうなったら | 直し方 |
|---|---|
| **画面が真っ白** | 数分待つ（GitHub Pages の反映に時間がかかります） |
| ★**直したのにスマホで変わらない** | ★**いちばん多い症状。** ホーム画面のアイコンを消して、Safari で開き直してから追加し直す |
| 404 が出る | Settings → Pages の Branch が `main` / `root` になっているか確認 |

## 遊び方

- **画面をタップ** … オーリー
- **画面を上へなぞる** … キックフリップ
- **画面を下へなぞる** … ポップショウビット
- 液晶の外のボタン … 音の入り切り / 一時停止 / もどる

★**画面のどこを触っても跳べます**（ボタンの上だけは除く）。

## ★いまは作りかけです

背景の山・ビル・木・草花は、**仕組みを確かめるために置いた仮の四角と線**です。
これから島さんが絵を描いて差し替えます。
